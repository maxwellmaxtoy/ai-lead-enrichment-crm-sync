# Setup Guide

This guide explains how to set up the AI Lead Enrichment & CRM Sync project.

## 1. Requirements

You will need:

- n8n
- Supabase
- Google Gemini API access
- Gmail OAuth credentials in n8n
- Google Forms
- Google Apps Script
